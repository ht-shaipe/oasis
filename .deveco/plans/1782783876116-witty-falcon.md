# Goal

Migrate all major management features from jishu-hub into Oasis: agent environment/config management, project management (meta/tags/notes, settings, merge/split), config presets/templates + backup/restore, custom commands, environment check, and enhanced tool classification.

# Scope / Non-goals

## In Scope
- **Persistence layer** (`~/.oasis/`) — session names, project metas, presets, hidden/manual projects, app state, project merges
- **Agent config** — load/save/backup/restore/export/import for `~/.claude/settings.json`; structured ClaudeConfig type
- **Project config** — per-project settings (shared + local), CLAUDE.md loading
- **Project meta** — custom_name, tags, notes per project
- **Project merge/split** — logical merge of multiple Claude project directories, undo via split
- **Config presets/templates** — system templates + user presets, apply/save/delete; Chinese API proxy presets
- **Config backup** — auto-backup on save, list/restore, cleanup (keep 10)
- **Custom commands** — CRUD + built-in agent command presets
- **Tool classification** — ToolKind enum in Rust backend, frontend integration
- **Environment check** — runtime + agent CLI detection, install/update
- **Settings UI** — new "Agent Config" panel (Config/Template/Backup tabs)
- **AgentChat sidebar UI** — enhanced with Projects/Commands/Env tabs

## Out of Scope
- ACP runtime / OpenCode adapter
- Auto-update system (Oasis has its own)
- Floating PiP session windows
- Image/file attachment in chat
- i18n for new features (add later)

# Current State And Constraints

## Oasis Existing State
- `oasis-agent` crate: 2 adapters (Claude Code, Codex), AgentRegistry with health_cache, streaming via Tauri events
- `oasis-project` crate: JSONL session parsing with smart_summary, parse_ai_title, load_session_info
- Agent Chat UI: sidebar with AgentHealthPanel, project list with agent_id badges, session list with display_name
- Settings app: 5 panels (General, Appearance, LLM, Embedding, About) — no agent config
- No `~/.oasis/` persistence layer
- No agent config management, no project meta, no presets/backup, no commands, no env check
- Tool classification is frontend-only (string matching)

## Constraints
- Rust edition 2024; macOS only (use `which`/`osascript`)
- Tauri commands auto-registered via `build.rs` scanning `#[tauri::command]`
- UnoCSS attribute mode; minimum font size 13px
- Vue 3 + Element Plus — all React components must be rewritten
- Pre-existing `oasis-local-llm` errors — do not fix

# Design

## 1. New Crate: `oasis-hub` — Persistence Layer

Path: `src-tauri/crates/hub/`

All persistent state under `~/.oasis/`:
```
~/.oasis/
├── state.json           — AppState
├── session_names.json   — session_id → custom name
├── presets.json         — user config presets
├── project_meta.json    — ProjectMeta per encoded_name
├── project_merges.json  — merge relationships
├── hidden_projects.json — hidden project encoded names
├── manual_projects.json — manually added project paths
└── commands.json        — CustomCommand entries
```

Port from jishu-hub `hub.rs` (729 lines), adapted for macOS and `~/.oasis/` path. Key types:
- `AppState` — active_agent_id, language, theme, font_size_base, font_size_prose, always_on_top, agent_binary_paths, agent_last_health
- `SessionNames` — HashMap<String, String>
- `Preset` — id, name, description, config (serde_json::Value for flexibility), created_at
- `ProjectMeta` — custom_name, tags, notes
- `ProjectMerges` — merges: HashMap<String, Vec<String>>
- `PhysicalMergeUndo` — primary, secondaries, timestamp (for split/undo)
- `HiddenProjects` — encoded_names
- `ManualProjects` — paths
- `CustomCommand` — id, name, command, agent_id, project_path

Key functions (all with `Result<T, Box<dyn Error>>`):
- State: `load_state()`, `save_state()`, `load_active_agent_id()`, `save_active_agent_id()`, `load_language()`, `save_language()`, `load_font_sizes()`, `save_font_sizes()`
- Session names: `get_session_names()`, `rename_session()`, `delete_session_name()`
- Presets: `list_presets()`, `save_preset()`, `delete_preset()`
- Project meta: `load_project_metas()`, `save_project_meta()`
- Project merges: `get_project_merges()`, `save_merge()`, `remove_merge()`, `get_mergeable_projects()`, `merge_projects_logical()`, `split_project()`
- Hidden projects: `hide_project()`, `unhide_project()`, `is_project_hidden()`
- Manual projects: `add_manual_project()`, `remove_manual_project()`, `load_manual_projects()`
- Commands: `list_custom_commands()`, `save_custom_command()`, `delete_custom_command()`

Helper: `read_json<T>()`, `write_json<T>()` using `atomic_write()`.

Project merge/split logic (from jishu-hub):
- `merge_projects_logical(primary, secondaries)` — creates symlink/junction from secondary `.claude/` dirs into primary project's `.claude/` dir, records undo data
- `split_project(primary)` — reverses the merge using undo data
- `get_mergeable_projects(encoded_name)` — lists projects that share the same decoded path prefix

Dependencies: `serde`, `serde_json`, `chrono`, `dirs-next`

## 2. New Crate: `oasis-agent-config` — Agent Configuration

Path: `src-tauri/crates/agent-config/`

Port of jishu-hub `config.rs` (286 lines) + `project_config.rs` (157 lines) + templates.

### Module structure:
- `src/lib.rs` — re-exports + ClaudeConfig type + config I/O
- `src/project.rs` — ProjectSettings, project config I/O, CLAUDE.md
- `src/templates.rs` — system config templates

### ClaudeConfig type (from jishu-hub, reads `~/.claude/settings.json`):
```rust
struct ClaudeConfig {
    model: Option<String>,
    env: Option<HashMap<String, String>>,  // flex deserializer
    enabled_plugins: Option<HashMap<String, bool>>,
    skip_dangerous: Option<bool>,
    permissions: Option<PermissionsConfig>,
    mcp_servers: Option<HashMap<String, McpServerConfig>>,
    api_provider: Option<String>,
    small_model: Option<String>,
    large_model: Option<String>,
    allowed_tools: Option<Vec<String>>,
    disallowed_tools: Option<Vec<String>>,
    hooks: Option<HashMap<String, Vec<HookMatcher>>>,
    sandbox: Option<SandboxConfig>,
    verbose: Option<bool>,
    max_turns: Option<u64>,
    context_compaction: Option<ContextCompactionConfig>,
    // + cleanup_period_days, extra_known_marketplaces, theme, additional_directories
}
```

Supporting types: `PermissionsConfig`, `McpServerConfig`, `HookAction`, `HookMatcher`, `SandboxConfig`, `ContextCompactionConfig`, `BackupEntry`, `ProjectSettings`, `Permissions`, `HookEntry`, `HookCommand`.

### Config I/O functions:
- `load_config()` → reads `~/.claude/settings.json`
- `save_config(config)` → merges with existing (preserves unknown keys), auto-backups first, atomic write
- `load_raw_config()` → returns `RawConfigInfo { content, format }` for agents without structured config
- `save_raw_config(content)` → atomic write
- `backup_config()` → copies to `~/.claude/backups/settings_YYYYMMDD_HHMMSS.json`, keeps last 10
- `list_backups()` → sorted by name descending
- `restore_backup(backup_path)` → validates JSON, atomic write
- `export_config(export_path)` → copy to arbitrary path
- `import_config(import_path)` → validate, backup current, write imported

### Project config (from project_config.rs):
- `load_project_settings(project_path)` → `<project>/.claude/settings.json`
- `save_project_settings(project_path, settings)` → ensures `.claude/` dir, atomic write
- `load_project_settings_local(project_path)` → `.claude/settings.local.json`
- `save_project_settings_local(project_path, settings)`
- `load_claude_md(project_path)` → `<project>/.claude/CLAUDE.md`

### System config templates (embedded):
- "Default" — empty config
- "Sandbox Mode" — `{ "permissions": { "defaultMode": "default" }, "sandbox": { "enabled": true } }`
- "Bypass Permissions" — `{ "permissions": { "defaultMode": "bypassPermissions" } }`
- "Zhipu API" — `{ "apiProvider": "zhipu", "env": { "ZHIPU_API_KEY": "" } }`
- "DeepSeek API" — `{ "apiProvider": "deepseek", "env": { "DEEPSEEK_API_KEY": "" } }`
- "Aliyun API" — `{ "apiProvider": "aliyun", "env": { "ALIYUN_API_KEY": "" } }`

Dependencies: `serde`, `serde_json`, `chrono`, `dirs-next`

# Risks And Compatibility

- **Claude config format** — `~/.claude/settings.json` is owned by `claude` CLI. Must preserve unknown keys on save (merge strategy).
- **Path encoding** — Claude Code encodes paths (replaces `/` with `-`). Already handled in adapter.
- **Config templates** — Claude-specific fields (apiProvider, mcpServers) only meaningful for claude-code. Codex falls back to raw config.
- **macOS-only terminal** — Simplified from jishu-hub's cross-platform code (osascript only).
- **Project merge** — Creates symlinks on macOS. Must handle edge cases (already-existing dirs, permission errors).
- **Backward compat** — `~/.oasis/` created on first use. No migration from `~/.jishu-hub/`.
