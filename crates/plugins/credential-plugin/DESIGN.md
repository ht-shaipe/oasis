# 凭证管理插件 UI/UX 设计方案

## 1. 设计目标

### 核心原则
- **安全第一**：敏感信息默认遮蔽，操作需确认，完整审计追踪
- **实用优先**：快速搜索、批量操作、常用功能一触即达
- **响应式设计**：适配不同屏幕尺寸（1280px-4K）
- **无障碍访问**：WCAG 2.1 AA 标准，键盘导航、屏幕阅读器支持

## 3. 各页面详细设计

### 3.1 凭证列表页
- **顶部搜索栏**：搜索框（支持名称/平台/用户名模糊搜索）+ 新建按钮
- **筛选面板**：平台下拉、分类下拉、状态切换（启用/禁用）
- **数据表格**：
  - 列：名称、平台、用户名、分类、状态、更新时间、操作
  - 操作：查看（眼睛图标）、编辑（铅笔图标）、复制、删除（红色，需确认）
  - 支持排序（按名称、更新时间）
  - 隔行条纹、悬停高亮
- **底部分页**：显示总数 + 分页控件（20条/页）
- **状态**：
  - 空状态：显示"暂无凭证，点击新建开始使用"
  - 加载状态：骨架屏
  - 错误状态：显示错误信息 + 重试按钮

### 3.2 凭证详情页
- **页面标题**：凭证名称 + 平台/分类标签
- **操作按钮组**：编辑、复制、删除
- **信息卡片**（2列网格）：
  - 用户名（可复制）
  - 密码（默认遮蔽，点击显示）
  - 平台（带图标）
  - 分类
  - 备注
  - 标签
  - 创建时间
  - 更新时间
  - 过期时间（如已过期，红色标记）
  - 扩展字段（动态渲染）
- **审计日志**：底部显示该凭证的操作记录

### 3.3 凭证编辑/创建页
- **表单布局**（2列网格，关键字段占满行）：
  - 名称（必填，占满行）
  - 平台（下拉选择，必填）
  - URL（可选）
  - 分类（下拉选择）
  - 用户名（必填）
  - 密码（必填，带生成密码按钮）
  - 备注（textarea）
  - 标签（tag输入）
  - 过期时间（日期选择）
  - 扩展字段（动态添加键值对）
- **验证规则**：
  - 名称：不能为空，长度2-50
  - 用户名：不能为空
  - 密码：不能为空，长度≥8
- **操作按钮**：保存（主按钮）、取消
- **状态**：
  - 新建模式：标题显示"新建凭证"
  - 编辑模式：标题显示"编辑凭证 - {名称}"
  - 提交中：按钮显示保存中
  - 错误：字段级错误 + 全局错误信息

### 3.4 导入导出页
- **导入区域**：
  - 文件选择器（支持拖拽）
  - 格式选择（JSON/CSV）
  - 预览表格（显示将要导入的数据）
  - 导入按钮
- **导出区域**：
  - 范围选择（全部/选中）
  - 格式选择（JSON/CSV）
  - 内容选项（包含密码/不包含密码）
  - 导出按钮
- **状态**：
  - 导入中：进度条
  - 导入完成：成功/失败统计
  - 导出中：加载状态

### 3.5 审计日志页
- **筛选条件**：时间范围、操作类型、凭证名称
- **日志表格**：
  - 列：时间、凭证名称、操作类型、结果、IP地址
  - 操作类型标签：创建（绿色）、更新（蓝色）、删除（红色）、查看（灰色）、导出（黄色）
- **操作按钮**：清除旧日志（需确认）
- **分页**：20条/页

### 3.6 设置页
- **主密钥配置**：
  - 状态指示器（已配置/未配置）
  - 修改密码表单（旧密码、新密码、确认密码）
  - 密码强度指示器
- **安全选项**：
  - 自动锁定时间（下拉选择）
  - 密码默认遮蔽（开关）
  - 导出时必须输入密码（开关）
- **数据库信息**：
  - 数据库路径（只读）
  - 数据库大小
  - 凭证总数

## 4. 交互规范

### 4.1 删除操作流程
1. 用户点击删除按钮
2. 弹出确认对话框："确定要删除凭证 {凭证名称} 吗？此操作不可撤销。"
3. 用户确认后执行删除
4. 删除成功后显示成功提示并刷新列表

### 4.2 密码可见性切换
1. 默认显示为 "********"
2. 点击"显示"按钮后显示真实密码（5秒后自动遮蔽）
3. 点击"复制"按钮复制密码到剪贴板（3秒后清除剪贴板）

### 4.3 表单验证
- 实时验证：失焦时触发
- 提交验证：点击保存时触发所有验证
- 错误提示：字段下方显示红色文本

### 4.4 键盘快捷键
| 快捷键 | 操作 |
|--------|------|
| Ctrl+N | 新建凭证 |
| Ctrl+F | 聚焦搜索框 |
| Ctrl+S | 保存当前编辑 |
| Escape | 取消当前操作/关闭对话框 |

## 5. 空/加载/错误状态

### 空状态模板
- 凭证列表为空：图标 + "暂无凭证" + "创建第一个凭证" 按钮
- 搜索结果为空：图标 + "未找到匹配的凭证" + "调整搜索条件" 提示
- 审计日志为空：图标 + "暂无审计记录"

### 加载状态模板
- 列表加载：3行骨架屏
- 详情加载：卡片骨架屏
- 操作加载：按钮显示加载动画

### 错误状态模板
- 数据库错误：错误信息 + "重新加载" 按钮
- 导入错误：错误详情 + "重新导入" 按钮
- 保存错误：字段级错误 + 全局错误横幅
