# WASM 插件示例

这是一个使用 WebAssembly 实现的计算器插件示例。

## 架构说明

```

│  │  ┌─────────────┐  ┌─────────────────────────┐   │   │
│  │  │  插件加载器  │  │    UI 渲染层             │   │   │
│  │  └─────────────┘  └─────────────────────────┘   │   │
│  └─────────────────────────────────────────────────┘   │

│  │  ┌─────────────────────────────────────────┐    │   │
│  │  │  沙箱环境                                  │    │   │
│  │  │  ┌─────────────────────────────────┐     │    │   │
```

## 优势

1. **动态加载** - 运行时加载插件，无需重新编译
2. **沙箱隔离** - WASM 运行在安全隔离环境中
3. **热更新** - 可以动态替换插件
4. **跨平台** - WASM 模块可移植

## 限制

1. **UI 渲染** - WASM 不能直接渲染 UI，需要通过主应用
2. **性能开销** - 主机与 WASM 的通信有成本
3. **复杂度** - 需要设计序列化/反序列化机制

## 构建和测试

### 1. 构建 WASM 插件

```bash
cd crates/wasm-plugin
wasm-pack build --target web --out-dir ../../plugins/wasm
```

### 2. 在主应用中加载

WASM 插件会被放置在 `./plugins/` 目录，主应用会在启动时自动扫描和加载。

### 3. 插件接口

WASM 插件需要实现以下接口：

```rust
// 元数据
pub fn metadata() -> PluginMetadata

// 获取状态
pub fn get_state() -> PluginState

// 执行操作
pub fn execute(operation: &str, value: f64) -> PluginState

// 处理按钮点击
pub fn on_button_click(button: &str) -> PluginState
```
